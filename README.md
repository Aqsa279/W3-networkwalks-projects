# Week 3 - Password Cracking Projects

## Overview
This repository contains my Week 3 practical cybersecurity projects completed during my Cybersecurity & Ethical Hacking training at Networkwalks Academy.

The projects focus on password security, password hash extraction, and password recovery techniques using different security tools.

## Learning Objectives
- Understand password hashing and password security.
- Learn password recovery techniques.
- Practice using John the Ripper (JTR).
- Understand dictionary-based password attacks.
- Explore browser-based password security tools.
- Learn AI-assisted security testing using HexStrike MCP.

## Project Modules

### 1. W3-PM1 - Password Cracking with John the Ripper
**Tools:** John the Ripper (JTR), Johnny GUI

Tasks:
- Install and configure John the Ripper.
- Extract the hash from a password-protected PDF.
- Perform password recovery using JTR.
- Explore the Johnny graphical interface.

### 2. W3-PM2 - Password Cracking with Networkwalks Tools
**Tools:** Networkwalks Hash Calculator, Networkwalks Password Cracker

Tasks:
- Extract a PDF password hash.
- Analyze the extracted hash.
- Use the Password Cracker tool.
- Understand password recovery through browser-based tools.
