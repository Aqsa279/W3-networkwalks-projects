
# W3-PM2 - Password Cracking with Networkwalks Tools

## 1. Project Overview
This project demonstrates password recovery using Networkwalks online Hash Calculator and Password Cracker tools.

The practical was performed as part of Week 3 Cybersecurity & Ethical Hacking training.

## 2. Objective
- Understand PDF password protection.
- Extract password hashes from PDF files.
- Use online hash calculation tools.
- Perform password recovery.
- Understand password security risks.

## 3. Tools Used
- Networkwalks Hash Calculator
- Networkwalks Password Cracker
- Web Browser
- Windows / Kali Linux
- My Locked PDF1.pdf (authorized lab file)

## 4. Methodology

### Step 1: Download the PDF
Download the encrypted training PDF file named My Locked PDF1.pdf.

### Step 2: Open Hash Calculator
https://networkwalks.com/hash-calculator/

### Step 3: Upload PDF
Upload the authorized locked PDF file to the Hash Calculator.

### Step 4: Extract Hash
Copy the complete PDF hash beginning with $pdf$.

### Step 5: Open Password Cracker
https://networkwalks.com/password-cracker/

### Step 6: Submit Hash
Paste the extracted hash into the Password Cracker and start the attack.

### Step 7: Recover Password
Wait for the tool to complete the password recovery process.

### Step 8: Verify Password
Open the protected PDF and enter the recovered password to verify access.
